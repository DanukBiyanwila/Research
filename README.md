# HazardNet Research Portfolio

A single-page research portfolio website for **HazardNet**, an AI-based natural disaster prediction, SOS emergency response, safe routing, rescue camp, and donation management system for Sri Lanka.

## Description

Sri Lanka is frequently affected by floods and landslides. Existing disaster warning systems often provide general alerts at district or regional levels, but users need personalized and location-specific safety information. HazardNet solves this by combining machine learning, real-time data, map services, mobile technology, and emergency support features.

This repository contains the front-end code for the research portfolio showcasing the project, utilizing a modern, responsive design built with **pure HTML and CSS (no JavaScript or frameworks)**. It features a CSS-only Dark/Light mode toggle.

## Individual Contribution

This portfolio highlights the individual contribution regarding the **Machine Learning-Based Flood and Landslide Risk Probability Prediction and Home Safety Assessment**. 

Key responsibilities included:
- Collecting and preprocessing flood and landslide datasets.
- Training Random Forest models.
- Generating 0.0 to 1.0 probability-based risk scores and mapping them to risk levels.
